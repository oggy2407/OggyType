# OggyType — Typing Performance Tracker

A full-stack typing test and learning platform designed to help users improve their typing speed, accuracy, and overall performance.

## 🚀 HOW TO OPEN THE PROJECT

Follow these simple steps to use the project:

### Step 1 — Download the Project

Download the project ZIP file from the provided source.

### Step 2 — Extract the ZIP File

Right-click the downloaded ZIP file and select **Extract All**.

Open the extracted project folder.

### Step 3 — Open the `public` Folder

Inside the project folder, open:

```text
public
```

### Step 4 — Open `index.html`

Inside the `public` folder, find and open:

```text
index.html
```

The OggyType website will open in your browser.

From there, you can explore the typing test, practice your typing skills, check your performance, and use the available learning features.

> **Tip:** `index.html` is the main webpage of the project and is the starting point for exploring OggyType.

---

## ✨ Features

* **Typing Test** — Practice with timed or word-count typing tests.
* **Live WPM & Accuracy** — See your typing speed and accuracy while typing.
* **Performance Graph** — View how your WPM changes throughout a typing test.
* **Typing Practice** — Improve your speed and accuracy through regular practice.
* **Learn Section** — Guided typing lessons with a visual keyboard and finger-positioning guidance.
* **History** — View previous typing attempts and track your progress.
* **Random Passages** — Typing passages are fetched from an external API with a local fallback when needed.
* **Simple Interface** — A clean, focused interface designed to make typing practice comfortable and engaging.

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Node.js, Express
* **Database:** SQLite with Better-SQLite3
* **API:** DummyJSON Quotes API
* **Development:** Visual Studio Code
* **Version Control:** Git & GitHub

## 📌 Project Overview

OggyType combines a focused typing-test experience with a structured learning section. Users can practice typing, monitor their WPM and accuracy, review their performance, and work through guided lessons to improve their typing skills.

The project is designed to be expanded into a complete typing platform with multiplayer races, leaderboards, user accounts, advanced statistics, and personalized practice features.
